Lets start with  Leetcode 217: Contains duplicates :
---

a. Most naive way to solve this would be a nested for loop approach, starting with an i loop from 0->n-1 where n is the num of elements in the array and another loop j from 1 to n-1

go on running j and checking if nums[i] == nums[j] if it gets hit for any conditon return true, else move ahead. if both for loops are exhausted then we return false. 

TC: O(n^2) and SC: O(1)

b. A better approach: Using the hashmap for visited numbers:
-> Create a hashset of visited
-> run a loop i from 0->n  
-> check if current array element is present in the hashset 
	-> if yes return true 
	-> if no then add current element into hashset
-> if the entire loop is exhausted without returning, return false
TC: O(n) & SC: O(n) (In the worst case every element is unique, so the HashSet stores all n elements.)

2. Missing Numbers:

a. one of the solution that I can think of: 
	-> Sort the given array 
	-> loop through it from start to finish and  compare it with a counter that start with 0 everytime 
		if current == counter 
		-> increment the counter 
	-> Edge case handling, if the above array passes without any issue then we handle an edge case where if the last element in the array != the size of the array then return it as the missing value

TC: 0(n log n) Sorting takes nlogn time & SC: O(1) 

b. We can reduce time complexity to O(n) by using the xor operator:
	-> run for loop from o->n 
	-> xor the range of elements
	-> xor the result of range of elements with the array elements 
	-> returned result is the missing numbers
TC: O(n) & SC: O(1)

3. Find All Numbers Disappeared in an Array

a. Similar to previous question
	-> Sort 
	-> create a res set & add all elements of our input array into set to remove duplicates 
	-> loop from 0->n
	-> check if an element is not present in the array, add that to a res array 
	-> return res 

TC: O(n) & SC:O(n) using extra set to deal with duplicates 

b. In place duplication marking is possible using -ve indexes
